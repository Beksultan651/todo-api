# TaskFlow

HTML, CSS және қарапайым JavaScript арқылы жасалған тапсырмалар менеджері.
Жинақтау құралы, React немесе API кілті қажет емес. Бұрынғы функционал
сақталды, сыртқы көрінісі толық жаңартылды. Репозиторийдің атауы өзгермеді.

## Іске қосу

1. ZIP файлын ашып, төрт файл тұрған қалтаны VS Code арқылы ашыңыз.
2. `index.html` файлын **Live Server** кеңейтімімен іске қосыңыз.
3. Пайдаланушылар мен алғашқы 30 тапсырма автоматты жүктеледі.
4. Басқа тапсырмалар URL-ін беру үшін **«API баптаулары»** панелін ашып,
   **«Загрузить задачи ↓»** батырмасын басыңыз.

Интернет қажет. `index.html` файлын тікелей ашуға да болады, бірақ
localStorage жұмысы үшін жергілікті HTTP серверін қолданған дұрыс.
Бұрын сақталған өзгерістерді көру үшін сол браузерді, мекенжайды және
портты қолданыңыз: localStorage сайттың origin мәніне тәуелді.

## Жаңа көрініс және тақырыптар

- **TaskFlow** атауы, күлгін акцент, жаңа қаріп өлшемдері, аралықтар,
  батырмалар және бөлгіштері бар тапсырмалар тізімі.
- Компьютерде сол жақта ықшам навигация; телефонда навигация жоғарғы
  бөлікке өтеді. Статистика үш үлкен карточканың орнына ықшам жолақпен
  және орындалу көрсеткішімен көрсетіледі.
- API мекенжайы, жүктеу нәтижесі және соңғы нақты сұраулар жиналатын
  **«API баптаулары»** панелінде орналасады.
- Күн/ай белгісі ашық және қараңғы тақырыпты ауыстырады. Барлық бет,
  өрістер, тізімдер, хабарламалар және модальды терезелер ортақ CSS
  айнымалыларын қолданады.
- Таңдау `taskflow.theme` кілтімен localStorage-та сақталады. Сақталған
  таңдау болмаса, `prefers-color-scheme` ескеріледі. Қолмен таңдағанға
  дейін жүйе тақырыбының кейінгі өзгерістері де қолданылады.
- Тақырыпты сақтау мүмкін болмаса, ескерту көрсетіледі; ағымдағы
  сеанста тақырып ауыса береді.

## Сақталған функционал

- API арқылы жүктеу, жүктелу күйі, түсінікті қателер және қайта жүктеу.
- Мәтін бойынша іздеу, автор/статус сүзгілері, статистика және
  көрсетілген тапсырмалар саны. Статистика жүктелген API таңдауы мен
  жергілікті өзгерістерді есептейді; бүкіл сервер статистикасы емес.
- Барлық пайдаланушы `limit=0` арқылы жүктеледі. Аты-жөні бойынша іздеу,
  A–Z/Z–A сұрыптау және жеке User ID өрісі бар. ID «Найти» батырмасымен
  немесе Enter арқылы ізделеді; табылмаған ID үшін хабарлама шығады.
- Пайдаланушы карточкасы немесе тапсырма авторы профильді ашады.
  Компьютерде профиль сол жақта, сол адамның тапсырмалары оң жақта;
  телефонда бөлімдер бірінің астына бірі орналасады.
- Профиль негізгі 30 тапсырмамен шектелмей, жеке endpoint-тен сол
  адамның барлық тапсырмасын алады. Тек анық көрсетілген профиль
  өрістері шығарылады; құпиясөздер мен банк деректері көрсетілмейді.
- Тапсырма қосу, мәтінін/авторын/статусын өңдеу, орындалды деп белгілеу,
  растау терезесі арқылы өшіру. Профильден қосқанда автор автоматты
  таңдалады; қажет болса өңдеу терезесінде ауыстыруға болады.
- Профиль мен негізгі тізім ортақ дерек қорын қолданады: автор өзгерсе,
  тапсырма жаңа автордың профиліне өтеді, екі тізімдегі статус бірдей.
- ×, «Отмена», Escape, профильдегі «← Назад» және браузердің Back
  әрекеті тек ең үстіңгі терезені жабады. Forward терезені қайта ашады.
  History API мен `popstate` қосарланған артқа өтуді болдырмайды;
  іздеу, сүзгілер, сұрыптау, өңдеу черновигі және айналдыру орны сақталады.

## API сұрыптауы

2026-10-16 күні ресми құжаттама және нақты жауаптар тексерілді:

- [Тапсырмалар құжаттамасы](https://dummyjson.com/docs/todos) `sortBy`
  және `order=asc/desc` параметрлерін қолдайды. Бұл жобада
  `sortBy=todo` қолданылады. Тапсырмалар тек жергілікті сұрыптаумен
  шектелмейді: әр өзгеріс нақты GET сұрауын жібереді.
- [Пайдаланушылар құжаттамасы](https://dummyjson.com/docs/users)
  `sortBy` және `order` қолдайды. Жоба `sortBy=firstName` қолданады.
  Бірнеше өріс бойынша серверлік сұрыптау бар деп болжанбайды.
  Бірдей есімдер арасындағы тектер ғана браузерде реттеледі;
  бұл айырмашылық интерфейсте жазылған.
- `/todos/user/{id}` үшін сұрыптаудың жеке мысалы құжаттамада жоқ.
  `/todos/user/1?limit=0&sortBy=todo&order=asc` және `desc` нақты
  тексерілді: жауаптар кері ретпен келді. Сондықтан профильде де
  нақты API сұрыптауы іске асырылған.
- «Исходный порядок» таңдауы `sortBy`/`order` параметрлерін алып тастап,
  жаңа сұрау жібереді. `URLSearchParams` арқылы `limit`, `skip` және
  қолданылған endpoint сақталады.
- Жүктеу мен қате күйлері әр тізімде жеке көрсетіледі. Қате болса,
  алдыңғы деректер сақталады. Әр сұрау нөмірленген: кеш келген ескі
  жауап жаңа сұрыптауды алмастырмайды.

**Нақты жіберілген GET сұраулары, барлығы HTTP 200:**

```text
https://dummyjson.com/todos?limit=30&skip=5&sortBy=todo&order=asc
https://dummyjson.com/todos?limit=30&skip=5&sortBy=todo&order=desc
https://dummyjson.com/users?limit=0&sortBy=firstName&order=asc
https://dummyjson.com/users?limit=0&sortBy=firstName&order=desc
https://dummyjson.com/todos/user/1?limit=0&sortBy=todo&order=asc
https://dummyjson.com/todos/user/1?limit=0&sortBy=todo&order=desc
```

Бұл URL-дер бөлек HTTP сынағында және қосымшаның оқиға өңдегіштерін
нақты DummyJSON-ға қосқан DOM интеграциялық сынағында қолданылды.
Соңғы тапсырмалар/пайдаланушылар URL-дері API панелінде, жеке
профиль сұрауы профиль ішінде көрсетіледі.

Әдепкі тапсырмалар URL-і: `https://dummyjson.com/todos?limit=30`.
Қолдау көрсетілетін енгізу: HTTPS арқылы `https://dummyjson.com/todos`
немесе `https://dummyjson.com/todos/user/ID`, параметрлері `limit`,
`skip`, `sortBy=todo`, `order=asc/desc`. Өзге параметрлер мен
endpoint-тер қате хабарламасымен қабылданбайды. **DummyJSON** батырмасы
өрістегі мекенжайды бастапқы мәнге қайтарады; жүктеу бөлек орындалады.

CRUD сұраулары: `POST /todos/add`, `PATCH /todos/{id}` және
`DELETE /todos/{id}`. Профиль ақпараты `GET /users/{id}` арқылы алынады.

## Жергілікті өзгерістердің сақталуы

**DummyJSON серверде өзгерістерді тұрақты сақтамайды.** Ол POST, PATCH
және DELETE жауаптарын имитациялайды. Сәтті жауаптан кейін осы сайт
өзгерістерді браузердің localStorage қоймасына сақтайды.

Тапсырмалар үшін бұрынғы `is.task-manager.v2` кілті сақталды, сондықтан
осы нұсқадағы бұрынғы жергілікті өзгерістер жоғалмайды.

- Сервер тапсырмалары `api-ID` тұрақты кілтімен біріктіріледі;
  жергілікті түзету сервердің ескі мәнінен басым болады.
- Өшірілген сервер тапсырмаларының ID тізімі сақталады, сондықтан
  қайта жүктеу немесе сұрыптау оларды қайтармайды.
- Жаңа тапсырмалар `local-…` бірегей кілтін алады. DummyJSON бірдей
  жаңа ID қайтара алатындықтан, бұл кілттер қайталануды болдырмайды.
  Жаңа тапсырманы кейін өңдеу/белгілеу/өшіру жергілікті орындалады.
- Негізгі тізім: API-ден жүктелген таңдау және жергілікті өзгерістер.
  Профильді ашудың өзі негізгі таңдауды кеңейтпейді, бірақ профильдегі
  өзгертілген тапсырма негізгі тізімге де кіреді.
- Сервер жауабының реті сақталады. Сервер білмейтін қосылған/өңделген
  жазбалар ғана браузерде сұрыпталып, сол ретке біріктіріледі. Бұл
  жергілікті қадам интерфейстегі түсіндірмеде бөлек көрсетілген.
- Толық профильдер localStorage-та сақталмайды. Қойма бұзылса не
  браузер сақтауды бұғаттаса, хабарлама шығады; ағымдағы сеанс жұмыс
  істейді, бірақ келесі ашылғанда өзгерістер қалпына келмеуі мүмкін.

## Тексеру нәтижесі

**Нақты DummyJSON HTTP сұрауларымен тексерілді:**

- Алғашқы 30 тапсырма, барлық пайдаланушы, жеке профиль және тапсырмалар.
- Жоғарыдағы алты сұрыптау URL-і және asc/desc жауаптарының реті.
- Қосымшаның өңдегіштерімен User ID іздеу, профильді ашу, POST арқылы
  қосу, PATCH арқылы мәтін/автор/статусты өзгерту, DELETE арқылы өшіру.
- Жергілікті тапсырманың қайта сұрыптаудан кейін бір рет қалуы,
  авторы өзгерген жазбаның басқа профильге өтуі және өшірілген
  жазбаның жаңа жауаппен қайтып келмеуі.
- CRUD-тан кейінгі GET серверде бастапқы деректердің сақталғанын растады.

**Бақыланатын API жауаптары бар автоматты DOM/CSS сынақтары өтті:**

- Екі тақырып, жүйе параметрі, сақталған таңдау, жүйе өзгерісі,
  қолмен таңдаудың басымдығы және localStorage қатесі.
- Нақты сұрыптау сұрауларының жасалуы, `limit`/`skip` сақталуы,
  жүктеу күйлері, қателер және ескі жауаптардың еленбеуі.
- Мәтін/ID іздеу, автор/статус сүзгілері, статистика, барлық CRUD
  әрекеті, жергілікті қайталанбайтын кілттер, өшіру белгілері,
  қайта ашу және өзгерістерді жоғалтпай біріктіру.
- Профильдегі толық жеке тізім, бос профиль, құпия өрістерді шығармау.
- Back/Forward, ×, Escape, жоғарғы терезені ғана жабу, қосарланған
  `history.back()` қорғанысы, черновик/сүзгілер/айналдыру орнын сақтау.
- CSS парсері, екі тақырыптағы мәтін түс жұптарының кемінде **4.5:1**
  контрасты, модальды терезелер мен өрістердің CSS айнымалылары,
  телефонда бағандарды тігінен орналастыру ережелері.

**Визуалды тексерілмеді:** браузерде ашық/қараңғы тақырыптың нақты
отрисовкасы, телефон эмуляторындағы және нақты телефондағы көрініс.
Браузер құралындағы қауіпсіздік шектеуі бұған мүмкіндік бермеді.
DOM/CSS сынағы толық визуалды тексеру деп есептелмейді. Дизайн
бұрынғы скриншоттарды қайталау мақсатынсыз дербес жасалды.

## Файлдар

- `index.html` — TaskFlow беті, API панелі және үш модальды терезе.
- `style.css` — тақырып айнымалылары, жаңа дизайн және бейімделу.
- `script.js` — API, тақырып, тапсырмалар, біріктіру, localStorage және тарих.
- `README.md` — іске қосу, API ерекшеліктері және тексеру нәтижесі.

Commit және push жасалған жоқ. Оларды VS Code арқылы өзіңіз жасай аласыз.
